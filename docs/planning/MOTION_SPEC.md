# Gymrez — قرارداد موشن
این سند پیشنهاد حرکتی تکمیلی است؛ PNG مرجع انیمیشن ندارد. موشن ظاهر ایستای PACE را تغییر ندهد.

| تعامل | رفتار | بودجه اولیه |
| --- | --- | --- |
| press/hover/focus | نور/opacity/scale بسیار کم، feedback فوری | 120–180ms |
| انتخاب H/R یا تب | indicator مشترک + fade محتوا، بدون نمایش داده پروفایل قبلی | 160–220ms |
| ورود صفحه/کارت | fade و جابه‌جایی اندک، stagger محدود | 220–300ms |
| sheet/modal | ورود/خروج کوتاه، focus trap و بازگشت focus | 220–350ms |
| ثبت ست | check و تأکید مختصر ردیف، حفظ محل scroll | 120–220ms |
| استراحت | نوار سگمنتی مرجع؛ زمان از deadline مستقل از animation | همگام با زمان واقعی |
| نمودار | رسم کوتاه فقط هنگام ورود/تغییر داده | 250–350ms |
| پایان تمرین | تیک موفقیت و تأکید آبی کنترل‌شده؛ pending با success اشتباه نشود | 250–350ms |
| loading | skeleton هم‌شکل محتوا، بدون layout shift | تا دریافت داده |

اعداد بودجه اولیه‌اند و پس از تست گوشی واقعی تنظیم می‌شوند. از Motion با import کم‌حجم و CSS استفاده شود؛ Lottie/WebGL/particle engine فقط اگر نیاز اثبات‌شده و بودجه performance اجازه دهد، نه به‌عنوان پیش‌فرض.

## قواعد
- transform/opacity اولویت؛ height/layout animation سنگین روی لیست حرکات و شمارنده ممنوع.
- interruptible باشد؛ کلیک بعدی منتظر پایان animation نماند.
- تصویر ورزشی و خطوط مورب هویت اصلی‌اند؛ assetهای سبک و با کیفیت، نه ویدئوی پس‌زمینه سنگین.
- prefers-reduced-motion: حذف translate/stagger/loop، حفظ feedback و اطلاعات. خاموش‌کردن موشن کل اپ را تست کن.
- تایمر متکی به raf یا setInterval نیست؛ پس‌زمینه و resume نباید زمان را تغییر دهند.
- صدا/لرزش opt-in با fallback برای مرورگرهای فاقد پشتیبانی؛ زمان قفل/بسته‌بودن PWA زنگ تضمینی وعده نده.
- keyboard focus، کنتراست، متن و اندازه لمس با حرکت خراب نشوند.
- شواهد T13/T19: کلیپ تعامل، تست لغو/تکرار، حالت بدون موشن و اندازه‌گیری روی گوشی هدف.
