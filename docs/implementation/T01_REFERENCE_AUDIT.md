# T01 — ممیزی مراجع PACE
تاریخ: 2026-11-16 · نتیجه: ممیزی منابع تکمیل؛ تطبیق محصول نهایی موضوع T21 است.

## شواهد قابل بازتولید
هر ۸ PNG در ابعاد اصلی 1536×1024 بازبینی شد. فرمان `npm run audit:design` اصل‌ها را بدون تغییر می‌خواند، SHA-256 می‌گیرد، ۲۵ پنل را crop می‌کند و [manifest](evidence/T01/reference-manifest.json) می‌نویسد. مختصات x/y/width/height در manifest است؛ حدود قاب به‌صورت دستی با خطای حدود ۲ پیکسل تعیین شده‌اند، نه داده اصلی Figma. خروجی crop را با اجرای فرمان بازتولید کنید؛ PNGهای تکراری بزرگ در گیت نگهداری نمی‌شوند.

این ابعاد raster مرجع هستند؛ گوشی واقعی ۳۱۳ یا ۴۷۵ CSS px فرض نشود. برای تست native، viewport برابر crop انتخاب شود؛ سپس ابعاد محصول 360/390/430/768/1440 نیز بررسی شوند. border بیرونی و گوشه‌های قاب در بعضی cropها چند پیکسل باقی دارند؛ هنگام overlay ماسک قاب استفاده شود.

## هندسه و تایپ
- شیت 01: desktop هدر لوگو/تم/H-R، hero سمت چپ، عنوان و action سمت راست؛ پایین ستون تقویم و ستون بزرگ برنامه هفته/امروز.
- شیت 02: هر پنل حدود ۴۷۵px raster؛ padding داخلی حدود ۱۸–۲۰px، تصویر player حدود ۴۴۰×۲۱۶px، CTA با ارتفاع حدود ۵۵px، border حدود ۱px. این‌ها اندازه‌گیری raster هستند و توکن CSS قطعی نیستند.
- در بقیه شیت‌ها عرض موبایل حدود ۳۱۳px raster است؛ قبل از انتقال اندازه‌ها، scale هر پنل مستقل در نظر گرفته شود.
- تیتر فارسی بسیار ضخیم، body فارسی متوسط، نام انگلیسی کوچک‌تر؛ نام دقیق فونت، وزن اصلی و kerning از PNG قابل اثبات نیست. وضعیت فونت **unresolved** تا T03؛ Tahoma اسکلت فقط placeholder است و پذیرش نهایی ندارد.
- لوگو italic/block با //؛ نیازمند استخراج یا بازسازی SVG با overlay، نه نوشتن متن با فونت تصادفی.

## رنگ‌های اندازه‌گیری‌شده
manifest پیکسل‌های پرتکرار یک ROI ثابت را برای هر شیت ثبت می‌کند؛ این داده‌ها raster هستند و رنگ اصلی طراحی محسوب نمی‌شوند.
نمونه‌های پرتکرار پس‌زمینه: 00 #041421، 01 #01121e، 02 #02131f، 03 #021422، 04 #07192a، 05 #001120، 06 #001321، 07 #000f1a.
تفاوت به texture/نور/تصویر مربوط است؛ یک hex واحد به‌عنوان «دقیقِ همه شیت‌ها» اعلام نشود. آبی CTA و رنگ border/text باید در T03 از ناحیه semantic مشخص نمونه‌گیری و با overlay تثبیت شوند. CSS اسکلت موقت است.

## نقص‌ها و تصمیم‌های تکمیلی
- nav شیت‌ها یکسان نیست: در 02 سابقه/تمرین، در 03 حرکات/برنامه و در 06 ساخت برنامه آمده است. ساختار ثابت خانه، برنامه/تمرین، پیشرفت/سابقه، پروفایل با دسترسی به library از برنامه/editor.
- شیت 06 ردیف‌های جلسات هفته را با هفته‌های ماه مخلوط می‌کند؛ ۳ جلسه در هفته در کل ماه تکرار شود، متن تاریخ از داده واقعی.
- نام مالک/نمایش پروفایل در برخی پنل‌ها با H/R نمی‌خواند؛ همه از context مجاز جاری گرفته شوند.
- بعضی اعداد تاریخ/جمع حجم/آمار نمونه‌اند. calendar شمسی و مقادیر محاسباتی واقعی ملاک، نه بازنویسی عدد غلط.
- saving/success هم‌زمان در یک PNG نمایان است؛ در محصول stateها جدا و موفقیت تنها پس از تأیید server.
- شیت 00 تم روشن دارد و 04 toggle؛ روشن باید از خانواده PACE تکمیل شود، ولی در اسکلت فعلی پیاده نشده.
- login/recovery/loading/empty/error/offline/conflict/نسخه جدید و ابتدای نصب در PNG نیست؛ با همان ساختار، بدون اختراع سبک جدید تکمیل شوند.
- انتهای فرم‌ها/دکمه‌ها و مسیر back باید کار کند؛ QR/play تزئینی قبول نیست.
- مقایسه داده پزشکی و داده واقعی کاربر در evidence عمومی نباشد.

## وضعیت پذیرش
T01 تنها آماده‌سازی مرجع است؛ هیچ ادعای تطبیق UI ساخته‌شده ندارد. اصل‌ها دست‌نخورده‌اند؛ hash و هندسه و منابع/ابهام‌ها ثبت شدند. نام فونت و assets تمیز باز و به T03 واگذار شده‌اند، بدون نسبت‌دادن مقدار حدسی به مرجع. خروجی اجرایی این نوبت T02 یک workbench فنی است و ظاهر محصول نهایی نیست.
