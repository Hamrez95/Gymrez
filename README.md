# Gymrez PACE

فضای تمرین حمیدرضا و ریحانه؛ رابط فارسی سرمه‌ای، برنامه‌ها و PDFهای خصوصی، اجرای جلسه و ثبت ست، تایمر استراحت، سابقه و نمودارهای واقعی بدن و تمرین.

**وب:** https://hamrez95.github.io/Gymrez/

برای داده‌های خصوصی، یک‌بار از فایل ورود اختصاصیِ تحویل‌داده‌شده وارد شوید. نشست روی همان دستگاه نگهداری می‌شود. لینک ورود یک credential است؛ آن را در issue، ریپو یا فضای عمومی قرار ندهید. بدون اتصال اختصاصی، داده‌های حالت پیش‌نمایش فقط روی دستگاه‌اند.

## امکانات نسخهٔ فعلی

- انتخاب سریع دو پروفایل و آواتارهای شخصی از Storage خصوصی؛ تصاویر واقعی در ریپوی عمومی نیستند.
- برنامهٔ فعال، آرشیو PDF و واردکردن بستهٔ استاندارد Gymrez با پیش‌نمایش و تأیید؛ انتخاب برنامهٔ فعلی عملیاتی جداست.
- نمایش شماتیک متحرک الگوی حرکت و نقشهٔ عضلات اصلی/کمکی؛ pause و حالت بدون موشن.
- ثبت ست و عملکرد قبلی، ترتیب سوپرست، تایمر مبتنی بر deadline و ادامهٔ جلسه.
- ذخیرهٔ تراکنشی در `workout_sessions` و `performed_sets` با کنترل revision و retry بدون تکرار.
- اندازه‌های بدن، BMI، نمودارهای واقعی، حجم وزنه، توزیع ست‌ها و تقویم ماهانهٔ شمسی.
- نصب PWA، تم روشن/تیره و کش پوستهٔ اپ. صف پایدار آفلاین برای ثبت تمرین و اندازه‌ها با همگام‌سازی هنگام بازگشت اتصال؛ بارگیری اولیه و واردکردن بایگانی ابری اینترنت می‌خواهد.

## اجرا

Node 24 و npm لازم است:

```sh
npm ci
npm run dev
```

متغیرهای عمومی در `.env.example` توضیح داده شده‌اند. فقط publishable key مجاز است؛ credential یا service-role key را وارد کد، env عمومی یا Git نکنید. `main` تنها شاخهٔ انتشار Pages است.

```sh
npm run typecheck
npm run lint
npm test
npm run build
npm run test:e2e
```
